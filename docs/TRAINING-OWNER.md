# ورقة المالك — صفحة واحدة

## الدخول
- البريد + كلمة المرور (مو PIN الموظفين).

## يومياً
1. **لوحة المعلومات**: مبيعات، خصومات، إلغاءات، أصناف خلصت.
2. **التقارير**: فلتر يوم/أسبوع/شهر + تصدير CSV/PDF.
3. **السجل (Audit)**: راجع الخصومات والإلغاءات وإبطال الفواتير.

## إدارة
- **المنيو**: أصناف، أسعار، صور، إخفاء، نفاد.
- **الطاولات**: إضافة / ترتيب / إيقاف (ما يوقف طاولة عليها فاتورة مفتوحة).
- **الموظفون**: إنشاء، تغيير PIN، دور، إيقاف حساب.
- **الإعدادات**: اسم الكوفي، هاتف، تذييل الإيصال، ساعة بداية يوم العمل.

## حساس
- **إلغاء فاتورة (Void)**: من تفاصيل الفاتورة — سبب إجباري — للمالك فقط.
- غيّر PINs الافتراضية فوراً بعد التسليم.
- لا تشغّل سكربتات التجربة (`db:seed:demo`) على قاعدة الإنتاج.
