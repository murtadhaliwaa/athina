# قائمة ما قبل التسليم (كاملة)

ضع علامة ✅ بعد كل بند. المرجع: `GUIDE.md` §18–§19.

## أ‌) المستودع والكود
- [ ] `npm test` ناجح
- [ ] `npm run build` ناجح
- [ ] `npm run lint` بدون أخطاء
- [ ] لا ملفات `.env` / `.env.local` / `OWNER_CREDENTIALS.local.txt` داخل أرشيف التسليم

## ب‌) إنتاج Supabase
- [ ] مشروع Supabase **منفصل** عن التطوير
- [ ] `prisma migrate deploy` على الإنتاج
- [ ] RLS مفعّل على كل الجداول (لوحة Supabase بدون تحذير)
- [ ] التسجيل الذاتي في Auth **معطّل**
- [ ] Storage bucket `menu-images` عام للقراءة حسب التصميم
- [ ] خطة مدفوعة أو نسخ احتياطي مجدول + تجربة استرجاع

## ج‌) متغيرات Vercel / الاستضافة
- [ ] `NEXT_PUBLIC_SUPABASE_URL` + anon/publishable
- [ ] `SUPABASE_SERVICE_ROLE_KEY` (خادم فقط)
- [ ] `DATABASE_URL` (pooler 6543 + `pgbouncer=true`)
- [ ] `DIRECT_URL` للـ migrations
- [ ] `PIN_PEPPER` قوي (32+)، محفوظ عندك وعند العميل
- [ ] `SEED_DEMO=0`
- [ ] نطاق HTTPS (مطلوب للـ PWA)

## د‌) بيانات حقيقية
- [ ] حساب مالك إنتاجي (بريد حقيقي + كلمة مرور قوية)
- [ ] موظفون بـ PIN غير `111111/222222/333333`
- [ ] طاولات حقيقية
- [ ] منيو + صور مرفوعة
- [ ] إعدادات الكوفي (اسم، هاتف، تذييل، ساعة يوم العمل)

## هـ) قبول يدوي §18.2 (جهازان)
- [ ] ويتر يرسل → يظهر عند الكاشير + صوت
- [ ] كاشير → جاهز → تنبيه للويتر صاحب الطلب
- [ ] ويتران على طاولة واحدة → فاتورة واحدة ورقمان
- [ ] حذف صنف في NEW ينجح؛ بعد PREPARING يُرفض للويتر
- [ ] إضافة على طاولة قيد التحضير → طلب تابع «إضافة»
- [ ] خصم بدون سبب يُرفض؛ بسبب ينجح
- [ ] دفعان متزامنان → واحد ينجح
- [ ] نفاد صنف يظهر «خلصت» ويرفض الإرسال
- [ ] تعطيل موظف → إجراءاته تُرفض
- [ ] إغلاق شفت بفاتورة مفتوحة يُرفض
- [ ] تغيير سعر لا يمس الفواتير القديمة
- [ ] قبل 05:00 يبقى الترقيم اليومي
- [ ] 5 PIN خاطئة → قفل
- [ ] تثبيت PWA على Android/iPad
- [ ] شاشات 360px / آيباد سليمة

## و‌) تدريب وتشغيل
- [ ] طباعة `TRAINING-WAITER.md` / `TRAINING-CASHIER.md` / `TRAINING-OWNER.md`
- [ ] يوم تجريبي بالتوازي مع الدفتر القديم
- [ ] اختبار قطع الإنترنت ثم الرجوع على جهاز الويتر

## ز‌) قرارات معلّقة (§20) — خارج النسخة الأولى
مخزون، طابعة تلقائية، تقسيم فاتورة، سقف خصم، ضريبة/خدمة، مصروفات صندوق، شعار إيصال.  
تُوثَّق مع العميل كمرحلة لاحقة — ليست نواقص في التسليم الحالي.
