# ورقة الكاشير — صفحة واحدة

## الدخول
- اسم المستخدم + PIN.

## بداية الشفت
1. **الشفت** → اكتب مبلغ الصندوق → **افتح الشفت**.
2. بدون شفت مفتوح: الويتر لا يقدر يرسل طلبات.

## الطلبات
1. لوحة **جديد → يتحضّر → جاهز → استلم**.
2. غيّر الحالة بزر كبير (ابدأ التحضير / جاهز / تم التقديم).
3. **الفاتورة** من البطاقة للدفع والخصم.
4. خصم: سبب إجباري (3 أحرف+). دفع: المبلغ المستلم ثم تأكيد.
5. إلغاء طلب: سبب إجباري. رفض طلب إلغاء الويتر من القائمة.

## نهاية الشفت
1. أغلق كل الفواتير المفتوحة أولاً.
2. عدّ الفلوس → اكتب المعدود → **أغلق الشفت**.
3. الفرق يراه المالك فقط — لا يظهر عندك.

## نفاد صنف
- من الشفت/التوفر: طفِ الصنف → يظهر «خلصت» للكابتن فوراً.
